# Student Performance Prediction

## About the Project

This project uses Machine Learning to predict student final performance based on academic and behavioral factors.

## Features Used

- Attendance
- Study Hours
- Previous Score
- Assignment Score
- Sleep Hours
- Participation

## Target

Final Score

## Machine Learning Algorithm

Linear Regression

## Dataset

The dataset contains 1000 student records.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## Project Workflow

1. Dataset creation
2. Data preprocessing
3. Feature selection
4. Train-test split
5. Linear Regression model training
6. Performance prediction
7. Model evaluation

## Files

- `Student_performance_prediction (3).ipynb` - Complete ML notebook
- `student_performance_dataset.csv` - Dataset containing 1000 student records
